## 本版变更

- 整体改为清爽原生风格：浏览、搜索、片库管理、设置、分析、说明统一字体、间距、控件及弹窗，使用不透明浅色/深色表面，保留橙色批量维护按钮。
- 浏览主页新增常驻“显示”入口，可切换竖版海报、完整封面、文字列表及详细视图；网格严格支持每行 2、3、5 部，小屏和最大字号下也保持所选列数。
- 每页影片数独立提供 30、45、60、90、120 部，并兼容已有 1–500 范围内的自定义数量。修改分页回到第 1 页，保留搜索和筛选；选择自动保存，与设置页同步，重启后恢复。
- 新增底部导航，统一 Android 原生弹窗及系统栏的浅深主题，调整设置页居中、窄屏按钮、长文字和横屏弹层布局。
- 修复首次加载时修改每页数量可能跳过影片、升级时旧分页数量和封面样式被默认值覆盖，以及保存其他设置覆盖主页显示偏好的问题。
- 修复升级后仍加载旧 JS/CSS 的缓存问题；继续保留封面视窗加载和离屏释放，避免每页 120 部时同时解码全部封面。
- 修复显示面板返回键、键盘及横向滚轮穿透，并恢复分析图表和图例中圆环与实心圆的形状区分。分段视频仍按一部统计。

## 验证

- 两套 Python 环境各通过 464 项测试；29 项 JavaScript 行为测试、131 个模块语法检查通过；458 个 Python 文件补丁回放一致。
- 模拟器使用 157 部逻辑影片、158 个视频文件验证分页、末页、筛选、重启保存及封面视窗；实际延迟首屏请求后修改分页，没有再跳过影片。
- 已检查简体中文、繁体中文、日文、英文，浅色/深色主题，320/360/412 像素宽度、字号及横屏，并验证四种语言的原生播放器弹窗。
- Android JVM 测试及 x86_64、arm64 构建通过。正式附件为 arm64-v8a 签名 APK，可覆盖升级原正式版。
