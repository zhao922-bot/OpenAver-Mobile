## 本版变更

- 图片相似新增 Qwen 百炼多模态图片向量协议，继续保留原有图片向量服务；地址、API Key 和模型独立配置。
- 人脸对焦新增 OpenAI 兼容视觉协议，提供 Qwen、DeepSeek、B.AI 地址预设和自定义连接，支持查询模型、自选测试图片及检测框预览。需要使用支持图片输入和位置输出的模型。
- 图片向量按服务、地址和模型隔离。切换连接后提示重新建立索引，旧任务和过期测试响应不会覆盖新连接的结果；云端人脸重建由用户明确发起。
- “缺简介”改为先搜索并保存原文，完成后再选择“保留原文”或“翻译这些简介”。只翻译所选批次，失败保留原文；刷新或中断后可以恢复待翻译入口，多个批次独立保留。
- 批量更换标签来源仅保留一个橙色“一键更换”按钮，选择来源后直接执行。取消预览和二次确认，失败项可按原来源单独重试。
- 移除 NFO 更新和标签更换中的备份选项、提醒及 `.openaver-backup` 生成逻辑；保留已有备份文件和原子写入。
- 修复短任务在保活服务启动完成前结束时，可能触发 Android 前台服务超时闪退的问题。

## 验证

- 两套 Python 环境各通过 449 项测试；129 个 JavaScript 模块语法检查通过。
- Python 补丁回放一致，Android JVM 测试及 arm64 构建通过。
- 专用模拟器验证了云端协议流程、简介搜索/翻译确认、单按钮标签流程及 NFO 界面；连续 10 次快速启动/结束任务未再闪退。

云端协议使用本地测试服务验证，未使用厂商真实付费凭据验证在线可用性或模型准确率。普通聊天模型或纯文本向量模型不能替代图片向量服务。
