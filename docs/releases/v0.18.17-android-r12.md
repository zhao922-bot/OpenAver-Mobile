## 本版变更

- 浏览页顶部常驻“排序”入口，与“显示”并列，提供日期、番号、标题、女优、片商、大小、修改时间和随机排序。常规排序可以切换升序、降序，并记住选择。
- 影片详情中的简介、头像对焦、标题翻译和剧照入口集中放在标题下方，标题独占一行区域，能够显示更多文字。操作按钮缩小为紧凑样式，并向外扩展点击区域。
- 修复“详细”视图标题与番号列错位，恢复表格单元格布局。
- 每行 3 部、5 部时分别缩小番号和标题字号，长番号自动换行完整显示。
- 相似影片页面增加银河星空背景、密集星群、闪烁亮星和封面光晕，并显示影片番号。缩小主封面和推荐封面，为星空留出空间，修正横竖屏封面重叠，支持系统减少动态效果设置。
- 加深播放、关闭等相关控件的半透明底色，提高浅色封面上的可读性，并适度提高禁用控件的可见度。
- 移除侧边吸附栏，将刷新、存储权限、SD 卡目录授权等入口集中到左上角菜单的“应用工具”，大屏侧栏也保留入口。同步更新各语言的存储授权提示。
- 修复排序菜单返回键关闭顺序，以及英文窄屏下菜单边缘超出屏幕的问题。

## 验证

- 两套 Python 环境各通过 464 项测试，29 项 JavaScript 行为测试通过。
- 模拟器完成 120 项排序、网格、详细视图及原生工具检查，并完成 9 项最终 APK 菜单边界、工具入口和半透明控件检查。
- 影片详情通过 16 组标题宽度、紧凑按钮排列及点击检查。相似影片使用中性测试封面，通过 11 组横竖屏、主题、钻取切换、返回和减少动态效果检查。
- 检查简体中文、繁体中文、日文、英文，浅色/深色主题，320/412 像素宽度及标准/最大字号。影片详情另外检查 320/360/412 像素及横屏下的标题宽度、按钮排列和点击行为。
- Android JVM 测试与 x86_64、arm64 构建通过。正式附件为 arm64-v8a 签名 APK。
