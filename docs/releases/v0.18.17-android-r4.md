## 本版变更

- 搜索页新增“图片查番号”：可从手机选择 JPG、PNG 或 WEBP，本地校验并缩放后查询；首次使用会提示图片将发送至第三方 `avscan.cc`，拒绝时不会发起请求。
- 图片查询结果最多展示 5 个候选，并显示相似度、匹配时间点和片库命中状态；无明确命中时不会自动搬动或整理文件，候选番号可带入普通搜索。
- 新增 OpenAI 官方翻译接入，固定使用 `https://api.openai.com/v1`，支持模型查询、测试翻译和参与现有标题补翻译。
- 片库灯箱简介支持按需读取 NFO `<plot>`，可切换原文/译文、翻译、写回和撤销；空简介和读取失败会显示明确状态，不会触发全库网络请求。
- 补充五种语言的 Web UI 文案，并保护灯箱异步读取、翻译和影片切换之间的状态竞争。

该版本使用移动端版本线 `v0.18.17-android-r4`，versionCode 为 `18004`。内嵌 Python 代码仍以 OpenAver `v0.17.18` 为基线，并按分阶段计划对齐上游 `v0.18.17` 的移动端相关功能。
