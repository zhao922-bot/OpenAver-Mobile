## 本版变更

- 新增完整韩文界面，简体中文、繁体中文、日文、英文和韩文现在共用同一套 Web UI、Android 原生菜单、确认框、启动状态和任务通知文案。
- 设置页整理为“来源”“命名”“片库”“AI 与服务”“系统”五个分页；仍使用单一表单，切换分页不会丢失未保存内容，刷新或直接访问链接可恢复当前分页。
- 手机说明页整理为“片库”“整理与改名”“排错与手动操作”三个页签，并兼容旧版说明页锚点。
- 新手引导缩短为四步，手机端会直接提示右侧菜单入口，并可从引导进入整理与改名说明。
- 继续保留 Jable、分段视频按 1 部计数、标题翻译、NFO 写回、数据库备份导入和 Android 前台任务保活。

该版本使用移动端版本线 `v0.18.17-android-r3`，versionCode 为 `18003`。内嵌 Python 代码仍以 OpenAver `v0.17.18` 为基线，并按分阶段计划对齐上游 `v0.18.17` 的移动端相关功能。
