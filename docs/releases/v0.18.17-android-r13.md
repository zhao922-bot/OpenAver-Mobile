## 本版变更

- 侧边菜单改为磨砂玻璃，模糊背后内容，解决页面文字透过菜单、影响阅读的问题。
- 设置页顶部导航及固定操作栏使用统一磨砂材质，滚动时底下的文字和控件不再清晰透出。
- 修复顶部导航与设置固定栏衔接处的细缝，防止滚动时露出底层文字笔画，并保持操作按钮对齐。
- 浅色和深色主题分别使用约 25% 的底色，结合背景模糊、渐变高光与边缘阴影，保留玻璃的通透层次。不支持背景模糊的设备使用不透明底色，保证文字可读。

## 验证

- 两套 Python 环境各通过 464 项测试，29 项 JavaScript 行为测试及 131 个 JavaScript 文件语法检查通过。
- 模拟器通过 12 组浅深主题、字号、屏幕宽度、滚动及菜单检查，并通过 4 组原生像素密度下的接缝绘制与按钮对齐检查。
- Android JVM 测试、x86_64 和 arm64 构建及 Python 补丁一致性检查通过。
