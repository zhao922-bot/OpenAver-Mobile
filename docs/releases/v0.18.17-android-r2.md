## 本版变更

- 查不到资料时显示可编辑的空白结果卡，支持修改番号、指定来源重新查询，以及手填标题、片商、演员、标签和日期。
- 支持上传本地封面并随手动资料一起整理入库；即使原视频没有 NFO，也会在最终目录中生成标题 NFO。
- 搜索页新增“常收女优”入口，按最近收片分数获取收藏女优近 90 天新片。
- 女优墙默认使用“最近常收”排序；远端照片候选每轮优先返回两张 Graphis 图片，并排除本轮已经看过的候选。
- 文件名含 LTX 时自动补充 `LTX` 和 `無碼破解` 标签，同时避免封面标章重复显示 AI 与 LTX。
- 灯箱中的用户标签可直接点击筛选；纯数字搜索后点击演员、片商、系列、导演、发行商、标签或发售日会自动清空数字。
- 继续保留 Jable、分段视频按 1 部计数、标题翻译、NFO 写回和 Android 前台任务保活。

该版本使用新移动端版本线 `v0.18.17-android-r2`，versionCode 为 `18002`。内嵌 Python 代码仍以 OpenAver `v0.17.18` 为基线，并按分阶段计划对齐上游 `v0.18.17` 的移动端相关功能。
